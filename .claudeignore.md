# .claudeignore (advisory)

Mostly advisory: Claude Code has no automatic `.claudeignore` support; §0 says what is enforced and how. Read this file before
exploring the repo. Skip the paths below unless the task needs that exact file, and use the cheap alternative instead.
Sizes are approximate, measured 2026-10-15.

## 0. Stay inside the game folder (all sessions and sub-agents)

* Work only inside the repository root. Don't read, search or write outside it, except your session scratchpad for previews and
  temporary scripts. Never run broad searches from `/`, `~` or a parent folder.
* Enforcement: `CLAUDE.md` (loaded automatically into every session and sub-agent) points here, and `.claude/settings.json` hard-denies
  reads of `.git/**`, `node_modules/**`, `.preview/audio/**` and `*.log`. Everything else in this file is advice.

## 4. Tests

- Don't read test files to learn the game. Run `node tests/run.mjs [filter]` (filter = substring of the file name).
- 18 `*.test.mjs` files, all passing on 2026-10-15, about 96 s in total. Slowest: chapter2 ~26 s, chapter3 ~19 s,
  walkthrough ~15 s, blackout ~9 s, flows ~8 s, audio ~5 s. The rest take under 4 s.
- The runner checks exit codes only: an empty test file passes, and a filter that matches nothing prints
  `no tests found` with exit 0.
- On failure it prints the last 15 stdout and 25 stderr lines. Read only that.
- `tests/harness.mjs` (91 lines) is the bot driver, `boot(seed)`. Read it only when writing a bot test.
- No test writes files, so they are safe to run any time.

## 6. Cheap facts

```bash
git log --oneline | head -5        # recent commits, no file reads
git status --short                 # uncommitted work
node tests/run.mjs [filter]        # 18 files, ~96 s in full
node tools/build-index.mjs         # rebuild index.html after any manifest edit; prints the script count (104)
node --input-type=module -e "import('./tools/load.mjs').then(m=>{const {NP}=m.loadNP();console.log(Object.keys(NP.data.species).length)})"   # 34, ~0.1 s, run from repo root
```

- Species ids: replace `.length` with `.join(' ')`. `NP.data.species` is an object keyed by id.
- Project notes: `README.md` "Status" (lines 42-49); art direction: `docs/ART-TARGET.md`.
