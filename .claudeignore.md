# Scope rules for Claude and all sub-agents

Claude Code does not read a `.claudeignore` file on its own. These rules are enforced in two places:
`CLAUDE.md` (loaded into every session and sub-agent automatically, and it points here) and the `deny`
list in `.claude/settings.json` (hard blocks on reads).

## Stay inside the game folder

* Work only inside the repository root (`kiguquest/`). Do not read, search, or write anything outside it,
  except the session scratchpad for previews and temporary scripts.
* Do not run broad searches from `/`, `~` or any parent folder.

## Never read (noise, generated, or binary)

| Path | Why |
|---|---|
| `.git/**` | history internals; use `git log` / `git show` instead |
| `node_modules/**` | not used by the game (no dependencies) |
| `.preview/**`, `*.log` | generated previews and logs |
| `index.html` | generated by `node tools/build-index.mjs`; edit `src/*/files.json` instead |
| `tools/sprites/*.png` | large source sheets; read the matching `.json` and only open a PNG when working on that import |

## Read only when the task needs it

| Path | When |
|---|---|
| `src/audio/**`, `docs/audio.md` | music or sound work |
| `src/data/**`, `docs/monsters.md` | stats, moves, items, balance |
| `src/maps/**`, `docs/STORY.md`, `docs/text.md` | levels, dialogue, story |
| `tools/balance-bot.mjs`, `tools/levels-overview.mjs` | balance work |

## Always relevant

`README.md`, `docs/DESIGN.md` (contracts and art rules), `docs/BIBLE.md`, and the area you are changing
(`src/<area>/` plus its `docs/` page and `tests/<area>.test.mjs`).
